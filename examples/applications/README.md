# Ejemplos de candidaturas

Esta carpeta contiene fixtures de prueba no canónicos. Se utilizan para comprobar workflows, prompts, validadores y generadores de CareerOS sin incorporarlos al historial real de candidaturas.

Los ejemplos:

- pueden utilizar descripciones realistas de ofertas públicas;
- no representan por sí mismos una candidatura real ni presentada;
- no forman parte del conocimiento canónico bajo `knowledge/`;
- no deben interpretarse como historial real de candidaturas;
- pueden contener análisis y planes de prueba sin que se hayan generado o enviado outputs.

Una instancia solo debe considerarse una candidatura activa o real cuando esa intención sea explícita y el expediente se traslade conscientemente a `career/applications/`. El traslado debe acompañarse de una revisión de sus metadatos, estado y procedencia; nunca debe inferirse solo por el contenido del ejemplo.
