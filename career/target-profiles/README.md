# Perfiles objetivo

Los perfiles objetivo son estrategias reutilizables para adaptar futuras salidas a familias de oportunidades. No son hechos canónicos, candidaturas ni textos finales. Seleccionan y jerarquizan evidencia existente bajo `knowledge/` y hacen explícitos los límites que toda generación debe respetar.

## Uso

1. Elegir el perfil cuyas señales de encaje correspondan mejor a la oferta.
2. Verificar cada afirmación futura contra las entidades enlazadas.
3. Aplicar la estrategia del canal requerido: CV, carta, entrevista o LinkedIn.
4. Si falta un hecho, registrar el vacío y actualizar primero la capa canónica cuando exista nueva evidencia.

El esquema está en [target-profile.schema.md](target-profile.schema.md) y la lista navegable en [index.md](index.md).

## Límites

- Un perfil no autoriza a inventar experiencia, títulos, métricas o tecnologías.
- Una transición o aspiración debe seguir identificada como tal.
- Las salidas generadas no se convierten en fuente de verdad para estos perfiles.
- Los cambios factuales pertenecen a `knowledge/`; los cambios de selección o posicionamiento pertenecen aquí.
