# Perfil objetivo: AI Backend Engineer

## Identidad y encaje

- **id:** `target-profile:ai-backend-engineer`
- **name:** AI Backend Engineer
- **purpose:** Orientar oportunidades que combinen backend sólido con integración de capacidades de IA aplicada y automatización, apoyándose en DEOS sin presentar experiencia profesional de ML.
- **target_titles:** AI Backend Engineer; Backend Engineer for AI Products; Applied AI Backend Engineer; Software Engineer, AI Applications; Python Backend Engineer para productos con IA cuando acepten experiencia emergente en Python.
- **best_fit_offer_signals:** Servicios backend para productos de IA; Python o FastAPI; pipelines de contenido o conocimiento; integración de modelos o APIs; automatización; RAG o agentes como contexto de producto sin exigir investigación de ML; valoración de experiencia Java transferible.
- **weak_fit_offer_signals:** Entrenamiento de modelos como núcleo; ML research; MLOps avanzado; experiencia profesional prolongada en Python obligatoria; ownership de modelos en producción; estadística o data science profunda.

## Posicionamiento

- **primary_positioning:** Ingeniero backend sénior que está trasladando su experiencia de sistemas e integración a productos de IA aplicada mediante DEOS, Python y FastAPI.
- **secondary_positioning:** Gestión del conocimiento; automatización; APIs; experiencia interdisciplinar; diseño de flujos de datos y componentes.
- **narrative_strategy:** Anclar la seniority en Java/Spring y producción; presentar DEOS como evidencia emergente y limitada de aplicación práctica; separar con claridad backend profesional de experimentación personal con IA.
- **must_emphasize:** Backend; diseño de APIs e integración; Python y FastAPI en DEOS; extracción, transcripción, resumen y organización temática; automatización; gestión del conocimiento; aprendizaje rápido.
- **should_include:** Sistemas críticos como señal de disciplina de ingeniería; proyecto de facturas; arquitectura de PulseCore solo si la oferta valora pipelines o diseño de datos.
- **should_deemphasize:** Unity3D, operación del negocio familiar, profundidad bancaria funcional y herramientas de infraestructura no centrales.
- **avoid_claims:** ML Engineer profesional; entrenamiento o evaluación de modelos; experiencia con LLMs en producción; escala, usuarios o despliegue de DEOS; dominio fuerte general de Python; automatización integral del pipeline.

## Estrategia por salida

- **cv_strategy:** Mantener primero la experiencia backend profesional y añadir una sección visible de proyectos aplicados; etiquetar DEOS como personal y no ocultar su evidencia limitada.
- **cover_letter_strategy:** Explicar la transferencia de prácticas backend a un producto con IA y describir el flujo de DEOS sin atribuir tecnologías o capacidades no registradas.
- **interview_strategy:** Preparar límites, estado y decisiones conocidas de DEOS; diferenciar integración de IA, ingeniería de producto y creación de modelos.
- **linkedin_strategy:** Mostrar interés y trabajo aplicado en IA junto al núcleo backend; evitar un titular que sugiera una trayectoria profesional consolidada en ML.
