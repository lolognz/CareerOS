# Instrucciones de exportación del CV

1. Abre `final/cv-print-es.html` en un navegador moderno.
2. Usa la opción **Imprimir** del navegador.
3. Selecciona **Guardar como PDF** como destino.
4. Elige papel **A4**.
5. Activa **Gráficos de fondo** si el navegador ofrece esa opción, para conservar todos los detalles visuales.
6. Mantén la escala en 100 % o en el valor predeterminado. Si el navegador añade márgenes extra, selecciona márgenes **Ninguno** o **Predeterminados** según cuál respete mejor los márgenes definidos por el documento.
7. Revisa la vista previa completa: comprueba que la foto se carga, que ninguna experiencia queda partida de forma incómoda y que el salto de página es limpio.
8. Guarda el PDF solo después de comprobar márgenes y salto de página en la vista previa.

El HTML ya define tamaño A4, márgenes de impresión y reglas para evitar cortes dentro de cada experiencia profesional.
