# Manuel's Manfred platform profile

## Purpose and status model

This file records the actual current working state of Manuel's profile in Manfred. It is channel-specific operational state, not canonical candidate knowledge and not a generated public profile.

The following labels distinguish provenance and maturity:

- **Platform field/prompt:** label or choice presented by Manfred.
- **Current value:** value currently selected, entered, or uploaded in Manfred.
- **Approved answer:** exact text explicitly settled and currently entered in Manfred.
- **Draft:** text still under review.
- **Unresolved:** missing information or a value whose meaning or final choice is not settled.

Canonical candidate facts must remain under `knowledge/`. Preferences and profile copy recorded here must not be promoted into canonical candidate knowledge or used to rewrite it.
